EasyIT Application

My project target is to build a Web Application, which will help by coding. Main feature would be Flash Cards that will display a method, their functionality and options. You can search them by framework  or language, you are implementing your code. Moreover you can hover over them to look up the symbol next to method to find out, what option it triggers.

This project has been developed as sum up of course "Complete Angular Course 2024 - Master Angular in only 6 days" and "Learn Spring Boot 3 in 100 Steps - No 1 Java Framework"
